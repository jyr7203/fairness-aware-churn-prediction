# Fairness-Aware Health Insurance Churn Prediction
### Orthogonalization + Threshold Tuning

건강보험 계약 해지(이탈) 예측 모델의 **그룹 공정성(group fairness)** 을 개선하기 위한 분석 프로젝트입니다.
채용·대출·의료와 같이 개인의 기본권에 큰 영향을 미치는 영역에서 자동화된 의사결정이 특정 집단에 불리하게 작동하면
평등권을 실질적으로 침해할 수 있습니다. 본 프로젝트는 계약 해지 예측이라는 고영향 의사결정 맥락에서,
나이·성별 및 그 대리변수(지역·사회경제 변수)에 따라 발생하는 집단 간 오분류율 격차를 완화하는 것을 목표로 합니다.

특히 **거짓양성률 격차(False Positive Rate Gap, FPR Gap)** 에 주목합니다.
FPR Gap은 *해지하지 않을 고객을 해지로 오분류하는 부담*이 집단 간에 얼마나 불균등한지를 측정하며,
이 부담이 특정 집단에 집중되면 그 집단이 부당한 개입(예: 불필요한 표적 관리)의 대상이 됩니다.

같은 절차를 **XGBoost** 와 **GLM(로지스틱 회귀)** 두 베이스라인 모델에 각각 적용합니다.

---

## 접근 개요

1. **Baseline** 모델(XGBoost / GLM)을 학습한다.
2. **전처리(pre-processing)** 로 피처에 숨은 간접차별 성분을 제거한다. (2가지 방법)
3. 검증셋 기준으로 최적 전처리 강도를 선택한다.
4. 선택된 모델 위에 **후처리(post-processing)** 로 그룹별 결정 임계값을 조정한다. (3가지 방법)
5. 민감변수 6개 각각에 대해 baseline 대비 공정성·성능 변화를 test셋에서 평가한다.

민감변수는 `age`, `gender`, `age×gender`, `C_H`, `C_GI`, `C_IE_T` 6가지입니다.
이 중 `C_H`·`C_GI`·`C_IE_T`는 자체가 보호속성은 아니지만 나이·성별을 간접적으로 담을 수 있는 **대리변수(proxy)** 입니다.

---

## 전처리 방법 2가지

각 수치형 피처에서 보호속성 기저(basis)로 설명되는 간접차별 성분을 제거합니다.
기저는 나이·성별로 구성합니다(연령대 더미 + 성별 + 나이×성별 + 나이 + 나이²).

| 방법 | 설명 |
|------|------|
| **CorrelationRemover** (fairlearn 표준) | 비민감 피처를 민감 피처로 선형회귀한 잔차로 대체한다. 강도 `alpha`로 조절하며 전 수치형 피처에 적용한다. |
| **Custom Orthogonalization** | 비선형 기저로 잔차화하되, 민감정보 함량($R^2$)이 임계값 $\tau$를 넘는 피처만 **선택적으로** 직교화한다. |

- 전처리 강도($\tau$, `alpha`)는 **PR-AUC 하락이 baseline 검증 성능의 2% 이내**라는 제약 아래에서 선택합니다.
- 최종 전처리 모델은 검증셋에서 **EO Gap이 최소**가 되는 지점으로 확정합니다.

---

## 후처리 방법 3가지

선택된 전처리 모델 위에 그룹별 임계값을 조정합니다. 방법마다 지향하는 공정성 기준이 다릅니다.

| 방법 | 지향 | 설명 |
|------|------|------|
| **FPR 균등화** | 집단 간 FPR 정렬 | 검증셋의 전체 FPR을 목표로, 각 그룹의 음성(y=0) 확률 분위수를 임계값으로 삼는다. 격차가 오히려 커지면 공통 임계값으로 되돌린다. |
| **ThresholdOptimizer** (fairlearn) | Equalized Odds | `equalized_odds` 제약으로 그룹별 최적 임계값을 학습한다. FPR과 TPR 격차를 함께 낮춘다. |
| **val-F1max** | 성능 우선 | 각 그룹에서 검증 F1을 최대화하는 임계값을 택한다. 성능은 가장 높지만 공정성 개선은 제한적이다. |

---

## 주요 결과 (Baseline → FPR 균등화 후처리, test 2019)

FPR 균등화를 적용했을 때 민감변수 6개 모두에서 FPR Gap이 크게 감소했습니다.

**XGBoost** (Baseline F1 = 0.413)

| 민감변수 | Base FPR Gap | 후처리 FPR Gap | 개선율 | 후처리 F1 |
|----------|:---:|:---:|:---:|:---:|
| age | 0.296 | 0.069 | **76.8%** | 0.389 |
| gender | 0.035 | 0.001 | **96.5%** | 0.404 |
| age×gender | 0.278 | 0.058 | **79.1%** | 0.388 |
| C_H | 0.234 | 0.121 | 48.3% | 0.401 |
| C_GI | 0.193 | 0.117 | 39.2% | 0.400 |
| C_IE_T | 0.167 | 0.052 | **68.7%** | 0.398 |

**GLM** (Baseline F1 = 0.358)

| 민감변수 | Base FPR Gap | 후처리 FPR Gap | 개선율 | 후처리 F1 |
|----------|:---:|:---:|:---:|:---:|
| age | 0.715 | 0.034 | **95.2%** | 0.344 |
| gender | 0.089 | 0.005 | **94.1%** | 0.356 |
| age×gender | 0.663 | 0.032 | **95.2%** | 0.344 |
| C_H | 0.216 | 0.043 | **80.2%** | 0.353 |
| C_GI | 0.249 | 0.061 | **75.5%** | 0.354 |
| C_IE_T | 0.326 | 0.045 | **86.2%** | 0.353 |

F1은 baseline 대비 소폭 변동에 그쳐, **예측 성능을 거의 희생하지 않고 공정성을 개선**합니다.

세 후처리 방법은 지향점에 따라 상충 관계를 보입니다. **FPR 균등화**는 FPR Gap을 가장 강하게 줄이고,
**ThresholdOptimizer**는 FPR과 TPR 격차를 함께 낮추어(GLM `C_GI`에서 FPR Gap 0.014, TPR Gap 0.096) 균형을 취하며,
**val-F1max**는 F1을 가장 높게(GLM 약 0.39) 유지하는 대신 공정성 개선 폭이 작습니다.
방법별·민감변수별 전체 수치는 각 노트북의 최종 비교표에서 확인할 수 있습니다.

---

## 공정성 지표

- **FPR Gap / TPR Gap / DP Gap**: 한 민감변수의 그룹들 사이 지표(거짓양성률 / 참양성률 / 양성예측률) 최댓값 − 최솟값. 0에 가까울수록 공정합니다.
- 그룹별 지표는 표본 수가 충분하고 양·음성이 모두 존재하는 그룹에 대해서만 계산합니다.

## 데이터

원자료가 아니라 **이미 전처리된 데이터셋(`.pkl`)** 을 입력으로 사용합니다. 이 데이터는 저장소에 포함하지 않으며,
노트북의 경로 설정 셀에서 본인 환경의 데이터 경로를 지정해 불러옵니다.

- **분할**: train(2017+2018) / validation(2018) / test(2019).
- 하이퍼파라미터와 임계값은 모두 validation(2018)으로 선택하고, 최종 성능·공정성은 test(2019)로 평가합니다.
- 다만 baseline·직교화 모델의 학습에 2018이 포함되어 validation이 완전히 독립된 holdout은 아니라는 점은 방법론의 한계입니다.

> 저장소의 `churn_model_*.pkl`은 학습된 **모델 패키지**이며, 위의 입력 데이터와는 다릅니다.
